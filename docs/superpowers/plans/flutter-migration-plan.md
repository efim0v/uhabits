## Как исполняется волна

Волны переносятся не по одной задаче в руках, а веером: реестр режется на слайсы
(одна фича или группа связанных), каждый слайс уходит отдельному агенту, который
идёт по циклу из `GOAL.md` — красный тест по правилам, порт кода, зелёный прогон.
Слайсы одной волны делятся на фазы по зависимостям: сначала листья без зависимостей,
потом производные, потом агрегаты.

Границы слайсов проводятся по файлам, а не по фичам: два агента никогда не пишут в
один файл. Общие точки (`lib/uhabits_core.dart`, `pubspec.yaml`, реестр, `PROGRESS.md`)
правит только оркестратор, после того как слайсы приземлились.

## W11 — локализации (сделана)

`uhabits-flutter/tool/convert_strings.dart` конвертирует все 49 наборов
`uhabits-android/src/main/res/values*/strings.xml` в ARB. Переносится 7869 сообщений,
50 файлов локалей.

Что оказалось нетривиальным:

- Android-плейсхолдеры `%1$s` и `%d` переводятся в ICU `{p1}`, а внутри plural — в
  `{count}`. Непозиционные `%s` нумеруются по порядку появления.
- ICU считает апостроф экранирующим символом, поэтому в сообщениях с фигурными
  скобками `'` удваивается — иначе часть строки молча исчезает.
- Android несёт легаси-коды языков Java: `in` → `id`, `iw` → `he`.
- Сербский в Android кодирует письменность регионом: `values-sr-rCS` — латиница
  (`sr_Latn`), `values-sr-rSP` — кириллица (`sr`).
- Для языков с несколькими регионами (`pt`, `zh`) Flutter требует базовый файл-фолбэк,
  иначе генерация падает целиком.

Перегенерация: `cd uhabits-flutter && dart tool/convert_strings.dart && cd app && flutter gen-l10n`.
