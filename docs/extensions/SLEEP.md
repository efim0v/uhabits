# Реестр расширений: цель по сну

Правила этой фичи не имеют прообраза в Kotlin — это расширение, а не перенос.
Формат совпадает с `docs/parity/FEATURES.md`: `- [ ]` не закрыто, `- [x]` закрыто
тестами, `- [~]` заменено более поздним правилом. Каждый тест цитирует id правила
в `reason:`.

Спецификация: `docs/superpowers/specs/2026-08-25-sleep-goal-design.md`
План: `docs/superpowers/plans/2026-08-25-sleep-goal.md`

- [x] `sleep.habit-type`
1. `sleep.habit-type#1` Отдельного типа привычки не заводится: HabitType остаётся двухэлементным, привычка со сном хранится как numerical.
2. `sleep.habit-type#2` Создание привычки со сном фиксирует atLeast, цель 100, частоту 1/1 и единицу «%».
3. `sleep.habit-type#3` Значение записи дня равно проценту, умноженному на 1000.
4. `sleep.habit-type#4` Наличие цели сна — единственный признак привычки со сном; без цели это обычная числовая привычка.
5. `sleep.habit-type#5` Удаление привычки удаляет её цель сна и все её ночи.

- [x] `sleep.stored-value`
1. `sleep.stored-value#1` Посчитанное значение в диапазоне 1…3 приводится к 0.
2. `sleep.stored-value#2` Значение выше 100000 обрезается до 100000.
3. `sleep.stored-value#3` Ноль остаётся нулём и не превращается в пропуск.

- [x] `sleep.goal`
1. `sleep.goal#1` Значения по умолчанию: 450 мин сна, веса 0.4/0.3/0.3, половинные баллы 90 и 60.
2. `sleep.goal#2` Веса нормируются к сумме 1 при чтении.
3. `sleep.goal#3` При нулевой сумме весов цель считается ненастроенной и день не оценивается.

- [x] `sleep.scoring`
1. `sleep.scoring#1` Отклонение времён круговое: min(|a-b|, 1440-|a-b|).
2. `sleep.scoring#2` Отклонение длительности одностороннее: пересып не штрафуется.
3. `sleep.scoring#3` Балл составляющей равен (1+exp(-k*m))/(1+exp(k*(d-m))) при k=0.05.
4. `sleep.scoring#4` Балл при нулевом отклонении равен ровно 1.
5. `sleep.scoring#5` Свёртка — взвешенное геометрическое среднее, не арифметическое.
6. `sleep.scoring#6` Длительность берётся как фактический сон, а не как разность подъёма и отхода.
7. `sleep.scoring#7` Контрольные векторы из раздела 4.3 спецификации.
8. `sleep.scoring#8` Разбор указывает составляющую с наибольшей потерей.

- [x] `sleep.timezone`
1. `sleep.timezone#1` Действующий пояс — чистая функция от истории наблюдённых смещений.
2. `sleep.timezone#2` Первый день пинится к домашнему поясу.
3. `sleep.timezone#3` Шаг задаётся наблюдением предыдущего дня, не текущего.
4. `sleep.timezone#4` Шаг ограничен скоростью адаптации по модулю в обе стороны.
5. `sleep.timezone#5` День без ночи наследует наблюдение ближайшего более раннего дня.
6. `sleep.timezone#6` Перелёт на 7 часов отрабатывает за 7 суток по таблице раздела 5.
7. `sleep.timezone#7` Ночь хранит пояс записи; пояс читающего устройства — ответ последней надежды.

- [x] `sleep.merge`
1. `sleep.merge#1` Источники группируются по bundle id, побеждает группа с наибольшей суммой сна.
2. `sleep.merge#2` При равенстве сумм побеждает лексикографически меньший bundle id.
3. `sleep.merge#3` Отрезки сна, разделённые не более чем порогом склейки, объединяются в цепочку.
4. `sleep.merge#4` Побеждает цепочка с наибольшей суммой сна, а не с наибольшим размахом.
5. `sleep.merge#5` asleepMinutes — мера объединения отрезков цепочки: каждая минута считается один раз, не размах и не сумма длин.
6. `sleep.merge#6` Границы берутся из пересекающихся отрезков inBed, иначе из цепочки с флагом derivedFromAsleep.
7. `sleep.merge#7` Логический день — календарная дата пробуждения в действовавшем смещении.
8. `sleep.merge#8` Настройка сдвига полуночи к привычке со сном не применяется.
9. `sleep.merge#9` Ручная запись за день побеждает запись из Health.

- [x] `sleep.stability`
1. `sleep.stability#1` Разброс круговой: времена вокруг полуночи дают малый разброс.
2. `sleep.stability#2` Пропуски и дни без данных исключаются из расчёта.
3. `sleep.stability#3` При числе пригодных ночей менее 4 разброс не рассчитывается.

- [x] `sleep.persistence`
1. `sleep.persistence#1` Миграция 100 создаёт SleepSessions и SleepGoals.
2. `sleep.persistence#2` База версии 25 поднимается до 100 без потери привычек.
3. `sleep.persistence#3` Повторный прогон миграции безопасен.
4. `sleep.persistence#4` Миграции расширений отделены от сгенерированных и начинаются со 100.
5. `sleep.persistence#5` Одна ночь на пару привычка-день.
6. `sleep.persistence#6` База с версией из пустого промежутка 26…99 отвергается: такую схему не писал никто, и штамповать её вперёд было бы гаданием.
7. `sleep.persistence#7` Версия, которую везёт сборка, отделена от последней версии Kotlin; все проверки «файл новее, чем мы понимаем» используют первую.

- [x] `sleep.sync`
1. `sleep.sync#1` Перечитываются последние 14 дней, не только вчера.
2. `sleep.sync#2` Свёртка идемпотентна: повторный прогон даёт те же записи.
3. `sleep.sync#3` Смена цели пересчитывает всю историю привычки.
4. `sleep.sync#4` Синтетический ноль не пишется никогда, поздние данные лечат день.
5. `sleep.sync#5` Отказ в доступе к Health не является ошибкой.
6. `sleep.sync#6` Отказ платформы записывается в лог; отсутствие плагина — нет.
7. `sleep.sync#7` Новая привычка со сном читается с платформы сразу, не дожидаясь возврата в приложение.
8. `sleep.sync#8` Там, где хранилища здоровья нет, доступ не запрашивается повторно.

- [x] `sleep.reminder`
1. `sleep.reminder#1` Напоминание в момент «действующая цель подъёма + задержка».
2. `sleep.reminder#2` Напоминание едет вместе с дрейфующей целью.
3. `sleep.reminder#3` Напоминание не приходит, если ночь за день уже есть.

- [x] `sleep.skip`
1. `sleep.skip#1` Пропуск диапазоном пишет Entry.skip на каждый день отрезка.
2. `sleep.skip#2` Пропуск задним числом разрешён без ограничений.
3. `sleep.skip#3` Пропуск ставится и снимается на один день из листа ввода ночи.
4. `sleep.skip#4` Смещение, отличающееся от предыдущей ночи на 120 минут и более, вызывает подсказку — только если скачок случился за последние семь дней.
5. `sleep.skip#5` Подсказка пропуска никогда не применяется сама.
6. `sleep.skip#6` Пересчёт не затирает день, отмеченный пропуском, даже если ночь за него есть.
7. `sleep.skip#7` Пропущенный день сохраняет записанную ночь: время хранится, зачёт — нет.
8. `sleep.skip#8` Подсказка о смене пояса показывается тостером и закрывается насовсем.
9. `sleep.skip#9` Ночь пишется только если время правили: отметка пропуска не выдумывает ночь, не отбирает её у часов и не меняет её пояс.

- [x] `sleep.suggest-goal`
1. `sleep.suggest-goal#1` Подсказка требует не менее 10 ночей из 14.
2. `sleep.suggest-goal#2` Подсказка требует медианного отклонения не менее 30 минут.
3. `sleep.suggest-goal#3` Подсказка требует кругового разброса не более 45 минут.
4. `sleep.suggest-goal#4` Подсказка цели никогда не применяется сама.
5. `sleep.suggest-goal#5` Отклонённая подсказка цели не возвращается, пока предлагается та же цель.

- [x] `sleep.ui`
1. `sleep.ui#1` Ячейка дня в списке показывает процент существующей числовой ячейкой.
2. `sleep.ui#2` Блок прошлой ночи показывает три составляющие с баллами.
3. `sleep.ui#3` Лента ночей: дни слева направо, время сверху вниз, прокрутка вбок.
4. `sleep.ui#4` Пропуск показан вертикальной ячейкой ровно на своём дне; записанная ночь остаётся видна. Ночи ниже половины — предупреждающим цветом.
5. `sleep.ui#5` При отсутствии данных и при отказе в доступе экран остаётся рабочим.
6. `sleep.ui#6` Редактор для типа «сон» показывает поля цели вместо полей числовой привычки.
7. `sleep.ui#7` Под каждой ночью подписаны день недели и число.
8. `sleep.ui#8` Лента ночей тянется до первой записанной ночи и открывается на последней.
9. `sleep.ui#9` На платформе без хранилища здоровья доступ не предлагается и отказ не приписывается.
10. `sleep.ui#10` Окно ленты измеряется по ночам и цели, ни одна ночь не выпадает.
11. `sleep.ui#11` В строке цели стоит время отхода и подъёма, а не «не менее 100 %».
12. `sleep.ui#12` Подпись шкалы влезает в жёлоб целиком и не режется.

- [x] `sleep.export`
1. `sleep.export#1` Привычка со сном экспортируется как числовая со значениями-процентами.
2. `sleep.export#2` Ночи экспортируются отдельным файлом SleepSessions.csv.

- [x] `sleep.backup`
1. `sleep.backup#1` Восстановление копии переносит цель сна на привычку с тем же uuid.
2. `sleep.backup#2` Ночи переносятся на идентификатор, который привычка получила здесь.
3. `sleep.backup#3` Признак ручного ввода переносится вместе с ночью.
4. `sleep.backup#4` Измеренная ночь из копии не затирает ночь, введённую здесь руками.

- [x] `sleep.freshness`
1. `sleep.freshness#1` Записанная ночь объявляется списку и виджетам одним каналом.
2. `sleep.freshness#2` Закрытая область не объявляет ничего.
3. `sleep.freshness#3` Синхронизация сначала читает платформу, затем проверяет, затем пишет.
4. `sleep.freshness#4` Утренний вопрос ставится своим планировщиком, вне пространства идентификаторов напоминаний.
5. `sleep.freshness#5` Синхронизация сна не задерживает ничего, у чего есть свой порядок в onResume.
6. `sleep.freshness#6` Любая запись из блоков сна перерисовывает экран целиком.

- [x] `sleep.time`
1. `sleep.time#1` Местное показание переводится в мгновение с уточнением смещения, а не одним просмотром.

- [x] `sleep.calendar`
1. `sleep.calendar#1` Ячейка календаря окрашивается тем сильнее, чем выше процент ночи.
2. `sleep.calendar#2` Шкала нелинейна: нижняя половина процента получает шестую часть диапазона.
3. `sleep.calendar#3` Записанный день всегда акцентнее пустого, на обеих темах.

- [x] `sleep.history`
1. `sleep.history#1` Непрочитанная история читается на глубину горизонта, а не на две недели.
2. `sleep.history#2` Достигнутая глубина записывается и только растёт.
3. `sleep.history#3` Прочитанная история не перечитывается: дальше катится только окно лечения.
4. `sleep.history#4` Прочитанная неглубоко дочитывается один раз.
5. `sleep.history#5` Чтение, выброшенное до записи, покрытием не считается.
6. `sleep.history#6` Одновременные синхронизации сливаются в одну; последовательные читают заново.

- [x] `computed.day-write`
1. `computed.day-write#1` Вычисленная запись дня сохраняет заметку человека.
